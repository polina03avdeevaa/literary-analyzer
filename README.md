# Анализ и сравнение литературных текстов

[Ссылка на веб-приложение](https://literary-analyzer.streamlit.app/).

## О проекте

Приложение предназначено для количественного анализа и сравнения литературных произведений. Оно позволяет добавлять тексты, сохранять основную информацию о них и исследовать их лексические и структурные характеристики.

Приложение разработано на Python с использованием Streamlit.

## Возможности приложения

- **Добавление текстов:** ручной ввод или загрузка текстовых файлов в формате .txt.
- **Метаданные произведений:** название, автор, язык, литературная форма, жанр, годы создания и публикации (задаются вручную)
- **Коллекция текстов:** просмотр добавленных произведений и удаление отдельных текстов или всей коллекции.
- **Количественный анализ:** подсчет символов, слов, уникальных слов и предложений, а также вычисление средней длины слова и предложения.
- **Анализ лексического разнообразия.** 

## Структура проекта

- `app/main.py` — интерфейс приложения и организация работы с текстами. 
- `app/style.css` - настроенный стиль интерфейса.

- `src/text_model.py` - заданные классы для представления текстов.
- `src/processing.py` - заданные функции для обработки текстов и вычисления количественных характеристик.
- `src/comparison.py` - заданные функции для сравнения произведений.

- `tests` — папка, хранящая автоматические тесты.
- `requirements.txt` - список внешних зависимостей. 
- `.gitignore` - файлы, исключенные из системы контроля версий. 

## Используемые библиотеки

- **Streamlit**. Библиотека для создания интерактивного веб-интерфейса.
- **NLTK**. Библиотека для токенизации текста. 
- **Pandas**. Библиотека для работы с табличными данными и экспорта результатов. 
- **Plotly Express**. Библиотека для построения графиков (с возможностью интерактива).

## Ограничения

- В текущей версии коллекция произведений хранится в состоянии пользовательской сессии. После завершения сессии процесс обнуляется, а добавленные тексты не сохраняются. 
- Количественные показатели и частотные характеристики описывают формальные свойства текста. Чтобы оценить его художественные особенности, этого недостаточно. Учитывайте это. 
- В текущей версии тексты не проходят через лемматизацию: процесс приведения словоформы к ее базовой, словарной форме — лемме. Это дает как плюсы, так и минусы.
- Подсчет предложений может быть неточным для сложных случаях.
